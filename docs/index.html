Knowledge is anchored to names

Models recall facts by name. Remove the name, and the knowledge is still there, only as a shadow.

Current benchmarks mostly follow a Name-to-Fact recall paradigm: the question names an entity, and the model is scored on the fact it returns. We find that LLM knowledge is lexically anchored: models possess extensive factual information but find it significantly difficult to retrieve without explicit name tokens. We call this hidden layer Shadow Knowledge.

Probing it: the Dual-Trait Association task

ShadowBench replaces the entity's name with “the subject.” The model reads an anonymized description of an entity (Trait A) and must choose, among hard-negative distractors, the answer that describes the same hidden entity (Trait B). To succeed it must first identify the latent entity, then associate a second fact with it.

Facts come from Wikipedia for three domains (Technology, Sports, Entertainment) and two popularity tiers (popular Upper, niche Lower). They are iteratively hardened (v1→v3) against shortcuts such as gendered pronouns and chronological cues, so that success requires latent association.

Finding 1: The Shadow Gap

We evaluate Llama-3-8B-Instruct, Qwen3-8B, GPT-5.4-mini, GPT-5.4, and Claude-Sonnet-4.6. Removing the entity name lowers accuracy, and the gap persists up to the frontier models.

Finding 2: The Illusion of Forgetting

Unlearning is usually audited with name-driven questions. If knowledge is anchored to names, that audit may only test the anchor. We unlearn Elon Musk from Qwen3-8B with Gradient Ascent (GA), Gradient Difference (GD+KL), and NPO (NPO+KL), then ask ShadowBench questions about him without the name. We measure the Latent Entity Leakage Rate (LELR): how often the model's reasoning trace still writes out the “forgotten” name while solving the question.

How to read it. Each panel follows one unlearning method for three epochs. The grey line (ROUGE) is how well the model still recalls the entity's facts when asked by name: it drops almost immediately, so by this measure unlearning looks successful. The blue dashed line (LELR) is how often the reasoning still names Elon Musk: it stays near 1.0. The green line is ShadowBench accuracy, which is 58.4–68.8% at the selected checkpoints. LELR only reaches zero when the model itself collapses (GD+KL, epoch 3).

Finding 3: Two ways unlearning leaks

Repeating the NPO+KL experiment across Technology, Sports, and Entertainment shows that the leakage depends on how popular the forgotten entity is.

Popular entities (Upper tier): explicit leakage

Popular targets leak explicitly: the model rebuilds the name in its reasoning. LELR is 74.0–92.2% across the three domains.

Niche entities (Lower tier): implicit leakage

Niche targets leak implicitly: no name appears (LELR 0.0%), yet the facts stay linked and shadow accuracy remains 60.0–90.0%. A name-based audit would not flag this.
